# پلتفرم تجمیع نمایندگان — نقطهٔ شروع توسعه

وضعیت: **ناقص، غیرقابل نصب، غیرقابل استفاده برای فروش**.
این بسته محصول نهایی و پایان فاز اول نیست. فقط دو جزء مستقل هسته و تست‌های پیشنهادی آن‌ها را دارد. PHP و Composer در محیط تولید فایل موجود نبود؛ تست PHP اجرا نشده است. هیچ اتصال واقعی، پرداخت، Migration، Installer یا UI در این بسته پیاده‌سازی نشده است.

## فایل‌ها
- `src/Domain/Accounting.php`: دلتا با تشخیص ابهام reset، محاسبهٔ هزینه با integer، نگهداری باقیماندهٔ کسری و کنترل overflow.
- `src/Domain/SubscriptionPolicy.php`: محاسبهٔ وضعیت از عوامل مستقل؛ شارژ کیف پول تعلیق دستی، انقضا یا اتمام سهمیه را پاک نمی‌کند.
- `tests/run.php`: تست‌های هسته؛ اجرا با `php tests/run.php` در PHP مدرن ۶۴بیتی.
- `docs/architecture.md`: تصمیمات و موانع پذیرش Production.

مبنای محاسبه در این هسته GB ده‌دهی یعنی یک میلیارد بایت و واحد پول ریال است. باقیمانده، کسر ریال است؛ باید به شکل integer همراه کیف پول در تراکنش ذخیره شود. برای مقادیر فراتر از integer، سرویس باید از محاسبات Decimal دقیق استفاده کند؛ این هسته به جای تبدیل به float خطا می‌دهد.

مرحلهٔ بعد: فراهم‌شدن PHP، Composer و MySQL برای ایجاد پروژهٔ Framework، اجرای Migration و عبور تست فاز اول. به علت شرط صریح اجرای تست در پایان هر فاز، فازهای بعدی هنوز شروع نشده‌اند.
